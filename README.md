##  Carlos   Adenge – CSS   Tips  for  Beginners

CSS is what makes websites look beautiful. Here are some useful tips I have learned:

- Always start with a CSS reset to remove default browser styles.
- Use CSS variables (`:root`) to store colors so you can change them easily later.
- Learn Flexbox first — it is the easiest way to center items and create layouts.
- Use `box-sizing: border-box` so padding does not break your layout.
- Keep your CSS organized by grouping related styles together.

**Useful CSS properties for beginners:**
- `display: flex`
- `justify-content: center`
- `align-items: center
- `gap: 1rem;`
- `border-radius: 8px`

## GitHub for Beginners

- GitHub is a platform used to store and manage code.
- A repository is where project files are stored.
- Branches allow users to work on changes separately.
- Commits save changes made to files.
- Pull requests allow team members to review changes before merging them.
- Issues help teams track tasks, bugs, and improvements.
- Collaboration allows people to work together on the same project.
- Markdown helps users format text using simple symbols.
